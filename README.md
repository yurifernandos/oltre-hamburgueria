# Oltre Hamburgueria - Website & Painel de Gestão

Website moderno, rápido e responsivo para a **Oltre Hamburgueria - Sesimbra**, incluindo catálogo de produtos, pedidos via WhatsApp / MB WAY / Multibanco e painel de edição em tempo real.

## Funcionalidades
- **Catálogo Completo:** Burgers clássicos, Smash, Chicken, Entradas, Bebidas e Sobremesas.
- **Carrinho Dinâmico:** Cálculo de taxas de entrega em Sesimbra, takeaways e extras.
- **Checkout Integrado:**
  - Pagamentos por MB WAY e Referência Multibanco (ifthenpay)
  - Notificação de pedido automática via WhatsApp da loja
- **Modo Gestão (Painel Integrado):**
  - Edição rápida de preços em tempo real
  - Gestão de disponibilidade de estoque (Disponível / Esgotado) com 1 clique
  - Edição de horários, morada, contactos e taxa de entrega

## Publicação
Este projeto é estático (HTML/JS/Tailwind CSS) e pode ser publicado diretamente via **GitHub Pages** ou **Vercel** sem necessidade de build server.
